# Carousel App

Локальное приложение на Streamlit, которое превращает тему или готовый экспертный текст в сильную Instagram-карусель. Модель (Gemini) выступает как маркетинговый стратег, контент-стратег и копирайтер одновременно: перед генерацией она внутренне анализирует аудиторию, задачу и лучший угол подачи, но пользователю показывает только готовые слайды.

## Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка .env

Скопируйте пример и вставьте свой ключ:

```bash
cp .env.example .env
```

Затем откройте `.env` и укажите:

```
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-3.6-flash
```

Бесплатный ключ можно получить на [aistudio.google.com/apikey](https://aistudio.google.com/apikey).

## Запуск

```bash
source .venv/bin/activate
streamlit run app.py
```

Приложение откроется по адресу `http://localhost:8501`.

## Основные функции

- **Проекты** — sidebar со списком проектов, каждый хранит описание бренда/эксперта, продукт, ЦА, позиционирование, tone of voice, цель контента, доп. инструкции и накопленные правки пользователя. Данные сохраняются локально между запусками.
- **Материалы проекта** — загрузка PDF, DOCX, TXT, MD; текст материалов учитывается при генерации.
- **Генерация карусели** — режимы «Тема» и «Готовый текст», карусель строится по смыслу (7–10 слайдов, hook → развитие → payoff → CTA), без выдуманных фактов и цифр.
- **Доработка по комментарию** — можно указать, что изменить в уже сгенерированной карусели; модель точечно правит, сохраняя сильные части. Правку можно запомнить для проекта.
- **История генераций** — все созданные карусели проекта сохраняются и доступны во вкладке «История».
